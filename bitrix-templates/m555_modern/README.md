# M555 Modern — сучасний шаблон для 1С-Бітрікс

Новий адаптивний шаблон для інтернет-магазину **m555.com.ua** (ТзОВ «Альянс Сервіс Україна»).

## Що всередині

```
m555_modern/
├── header.php              # шапка: топбар, логотип, пошук, телефон, кошик, меню каталогу
├── footer.php              # підвал: колонки, контакти, соцмережі, кнопка «нагору»
├── template_styles.css     # дизайн-система + усі стилі шапки/навігації/підвалу + адаптив
├── styles.css              # стилі контентної області (текст сторінок з адмінки)
├── script.js               # липка шапка, бургер-меню, дропдаун каталогу, кнопка «нагору»
├── description.php         # назва/опис шаблону для адмінки
├── preview.html            # СТАТИЧНЕ прев'ю дизайну головної (відкривається у браузері без CMS)
├── images/                 # місце для зображень шаблону
├── include_areas/          # редаговані області, що включаються
└── components/             # кастомні шаблони компонентів під цей дизайн
    └── bitrix/
        ├── menu/
        │   ├── m555_top/        # верхнє службове меню (тип "top")
        │   ├── m555_catalog/    # меню каталогу у випадному списку (тип "left")
        │   └── m555_footer/     # меню підвалу (тип "bottom")
        └── breadcrumb/
            └── m555/            # хлібні крихти
```

## Як подивитися дизайн прямо зараз (без сайту)

Відкрийте файл **`preview.html`** у будь-якому браузері (подвійний клік).
Це повноцінне прев'ю головної сторінки на бойових стилях шаблону — щоб
показати, як виглядатиме сучасний сайт. Дані в прев'ю — демонстраційні.

## Встановлення на сайт (1С-Бітрікс)

> Робіть зміни спершу на тестовій копії сайту, а не одразу на «бойовому».

1. **Завантажте папку** `m555_modern` на сервер у каталог:
   ```
   /bitrix/templates/m555_modern/
   ```
   (через FTP/SSH або через «Адмін. панель → Контент → Структура сайту →
   Файли і папки»).

2. **Підключіть шаблон до сайту:**
   `Налаштування → Налаштування продукту → Сайти → Список сайтів →`
   виберіть сайт → вкладка **«Шаблон»** → у правилі за замовчуванням
   виберіть **«M555 Modern»** → зберегти.

   Для української версії (`/ua/`) підключіть шаблон до відповідного сайту
   або додайте правило за умовою.

3. **Меню.** Шаблон використовує стандартні типи меню Бітрікс:
   - `top` — верхнє службове меню (рядок над шапкою). Файл `top.menu.php`.
   - `left` — меню каталогу (кнопка «Каталог товарів»). Файл `left.menu.php`
     у корені каталогу `/catalog/`.
   - `bottom` — меню підвалу «Покупцям». Файл `bottom.menu.php`.

   Якщо цих типів меню ще немає — створіть їх через
   «Контент → Структура сайту → Файли і папки → … → Меню» з відповідними
   типами. Поки пункти меню порожні — блоки просто не відображаються,
   решта шаблону працює.

4. **Контакти, адреса, телефони** задані прямо у `header.php` та `footer.php`
   (вгорі файлів — змінні `$PHONE_MAIN`, `$EMAIL`, тощо). Відредагуйте за потреби.

5. **Пошук** надсилає запит на сторінку `/<розділ>/search/` (стандартна
   сторінка пошуку Бітрікс). Якщо у вас інша адреса пошуку — змініть `action`
   у формі в `header.php`.

6. **Кошик** веде на `/<розділ>/personal/cart/`. Якщо у вашому магазині
   інший шлях кошика — поправте посилання `ha--cart` у `header.php`.

## Як побудовано (важливо)

- Шаблон **не змінює структуру каталогу та товари** — він лише змінює
  «обгортку» (шапку/підвал/стилі). Списки товарів, картка товару, кошик
  тощо залишаються вашими наявними компонентами.
- Усе зав'язано на **стандартні компоненти ядра** (`bitrix:menu`,
  `bitrix:breadcrumb`), тому шаблон сумісний із наявним сайтом без доступу
  до його файлів.
- Дизайн адаптивний: десктоп, планшет, телефон (бургер-меню < 900px).

## Головна сторінка

Готовий приклад вмісту головної — у файлі **`index.example.php`**.
Скопіюйте його вміст у головну сторінку сайту (`/index.php` або `/ua/index.php`),
вкажіть `$IBLOCK_ID` вашого каталогу — і отримаєте герой, сітку категорій,
блок «Хіти продажів», акційні банери та переваги (як у `preview.html`).

Використані компоненти та їхні шаблони з цього набору:
- `bitrix:catalog.section.list` → шаблон **`m555_categories`** (сітка категорій);
- `bitrix:catalog.top` → шаблон **`m555_hits`** (картки товарів).

Стилі блоків головної — у **`home.css`** (підключається з `index.example.php`).

## Сторінки каталогу

- **Список товарів у розділі:** компонент `bitrix:catalog.section`,
  шаблон **`m555_list`** (картки + сортування + пагінація).
- **Картка товару:** компонент `bitrix:catalog.element`,
  шаблон **`m555_detail`** (галерея + ціна + кнопка «Купити» + характеристики).

Якщо каталог працює через комплексний компонент `bitrix:catalog`, у його
налаштуваннях («Шаблони компонентів») вкажіть ці імена шаблонів для
відповідних сторінок (`section`, `element`).

Стилі каталогу — у **`catalog.css`**. На сторінках каталогу підключайте
**`home.css` + `catalog.css`** (картки товарів беруться з `home.css`):

```php
$APPLICATION->SetAdditionalCSS(SITE_TEMPLATE_PATH . "/home.css");
$APPLICATION->SetAdditionalCSS(SITE_TEMPLATE_PATH . "/catalog.css");
```

## Налаштування дизайну (кольори / лого)

**Кольори.** Уся гама — у CSS-змінних на початку `template_styles.css`
(секція `:root`):

```css
--c-brand:  #1853d6;  /* основний колір */
--c-accent: #ff6a2b;  /* акцент для кнопок/цін */
--radius:   16px;     /* заокруглення */
```

Готові варіанти палітри зібрані у **`theme.example.css`** — просто
скопіюйте потрібний блок `:root` у кінець `template_styles.css`.

**Логотип.** Покладіть файл `logo.svg` або `logo.png` у папку
`m555_modern/images/` — шаблон автоматично покаже картинку замість
текстової плашки. Нічого редагувати не треба.

## Банер-слайдер на головній

Замість статичного героя головна використовує слайдер (компонент
`bitrix:news.list`, шаблон **`m555_slider`**). Слайди беруться з окремого
інфоблоку «Банери»:

- **Назва** → заголовок слайда;
- **Анонс** → підпис;
- **Картинка** (анонсна/детальна) → фон слайда;
- властивість `LINK` (рядок) → куди веде слайд (необов'язково);
- властивість `BTN` (рядок) → текст кнопки (необов'язково).

Слайдер самодостатній: автопрокрутка, стрілки, крапки, свайп на телефоні
(CSS у `home.css`, JS у `script.js`). Якщо інфоблоку банерів ще немає —
у `index.example.php` показано, як тимчасово лишити статичний герой.

## Кошик і оформлення замовлення

Файл **`cart.css`** стилізує **стандартні** компоненти
`bitrix:sale.basket.basket` та `bitrix:sale.order.ajax` під тему (кнопки,
поля, підсумки, кроки оформлення). Логіка компонентів не змінюється —
лише вигляд. Підключіть `cart.css` на сторінках кошика та оформлення:

```php
$APPLICATION->SetAdditionalCSS(SITE_TEMPLATE_PATH . "/cart.css");
```

## Фільтр каталогу

Стандартний `bitrix:catalog.smart.filter` стилізовано під тему у `catalog.css`
(заголовки, чекбокси, повзунок ціни, кнопки). Для розкладки «фільтр зліва +
список справа» обгорніть блоки у `<div class="catalog-layout">…</div>`.

## Преміальний вигляд (glassmorphism)

Дизайн побудований на «скляних» (прозорих із розмиттям) елементах:
шапка, картки, випадне меню, кнопки-пігулки з градієнтом, багатошаровий фон.
Скло реалізовано через `backdrop-filter` + CSS-змінні `--glass*` у
`template_styles.css`. Працює у всіх сучасних браузерах; у дуже старих
просто показується суцільний фон (зображення лишається читабельним).

## Торгові пропозиції (SKU), обране та порівняння

- **SKU-варіанти** на картці товару (`m555_detail`): перемикач варіантів
  оновлює ціну та посилання купівлі (JS у `script.js`, стилі в `catalog.css`).
  Працює з пропозиціями (`OFFERS`) компонента `bitrix:catalog.element`.
- **Схожі товари** — блок унизу картки товару (популярні з того ж каталогу).
- **«В обране»** — кнопка на картках і детальній веде на стандартну дію
  відкладених товарів кошика (`?action=DELAY&id=…`).
- **«Порівняння»** — кнопка додає товар у стандартний список порівняння
  (`?action=ADD_TO_COMPARE_LIST&id=…`). Сторінку порівняння
  (`bitrix:catalog.compare.list`) стилізовано в `catalog.css`.

> Кнопки «обране/порівняння» зʼявляються при наведенні на картку
> (на тач-екранах — завжди видимі).

## Темна тема та анімації

- **Темна тема:** кнопка-перемикач (сонце/місяць) у шапці. Вибір
  зберігається у браузері (`localStorage`), а за замовчуванням
  враховується системна тема пристрою. Реалізовано через
  `html[data-theme="dark"]` + ранній інлайн-скрипт у `<head>` (без миготіння).
- **Поява при скролі:** блоки з класом `reveal` плавно зʼявляються при
  прокрутці (IntersectionObserver). Поважає `prefers-reduced-motion`.
  Щоб увімкнути для свого блоку — додайте йому клас `reveal`.

## Прев'ю

- `preview.html` — головна сторінка (спробуйте перемикач теми у шапці).
- `preview-product.html` — сторінка товару (SKU, галерея, схожі товари).
